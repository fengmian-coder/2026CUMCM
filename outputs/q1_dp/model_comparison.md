# 第一问 MILP 与动态规划模型对比

两种方法使用相同的144个十分钟时段、购电价格、负载、光伏预测、储能效率、容量边界、充放电功率限制及首尾储电量约束。附件中的时刻按区间右端点解释，例如 `00:10` 对应 `00:00-00:10`。

## 可用于论文的结论

动态规划结果随储电量离散步长减小而稳定逼近MILP连续最优解。步长由200 kWh减小到5 kWh后，费用差从1129.60元降至24.18元，相对误差由3.2158%降至0.0688%，说明Bellman递推能够正确刻画储能状态的跨时段耦合关系。动态规划的误差主要来自储电量状态离散，而不是供需平衡或储能约束违反。

5 kWh网格下，储电量保持在1200-10800 kWh范围内，日初和日末均为6000 kWh，没有同时充放电，最大功率和逐时段能量平衡约束均满足。该结果可作为MILP解的独立交叉验证。

MILP直接处理连续储电量，能够得到更精确且计算更直接的主结果；动态规划清晰展示“当前储电状态-阶段决策-未来价值”的递推关系，适合作为论文中的对比模型和稳健性验证方法。
